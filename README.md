# Youtube-Anti-Playables
On YouTube, the "Youtube Playables" box is really performance consuming.
This script will automatically close this box regardless the account you're using, it also works when you're not logged in.

## Installation
1. You need a plugin installed in your browser to run this script on youtube.com opening. This script uses [Tampermonkey](https://www.tampermonkey.net/).
2. Copy Paste the content of `tampermonkey.js` in a new script in the plugin.
3. ℹ️ If your browser is not in English and not in French, add the Playables box title to the array on line 17.
